# Schemas

MVP uses flexible JSON payloads around the active State-centric loop:

- `Current State`: accepted project cognition
- `Evidence Episode`: imported work/session evidence
- `Cognitive Diff`: detected state-relevant change
- `State Patch Proposal`: proposed state mutation requiring confirmation
- `Cognitive Event`: accepted state transition record
- `System Event`: operational activity record

Entity/Candidate promotion is no longer part of the active schema model.
